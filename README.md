# Best-looking food picture

A steaming bowl of tonkotsu ramen: glossy broth, wavy noodles, a
soft-boiled egg with a runny yolk, charred chashu, scallions and nori,
in warm golden light.

`main.py` (Python standard library only, no network) copies the image
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`),
byte for byte, so repeated runs produce identical output.
